2. What will be displayed by this program?
public class Test {
  private int i = 0;
  static int j = 0;

  public static void main(String[] args) {
    new Test();
  }

  public Test() {
    i++; 
    j++;
    int i = 1;
    int j = 1;
    System.out.println("i is " + j + " j is " + j);
  }
}

A. i is 0 j is 0
B. i is 1 j is 1
C. i is 2 j is 2
D. i is 0 j is 1
E. i is 1 j is 0
