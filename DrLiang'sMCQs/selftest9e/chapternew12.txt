19.	SansSerif, Serif, Monospaced, Dialog, or DialogInput are the only fonts you can use.
a. true
b. false
Key:b SansSerif, Serif, Monospaced, Dialog, or DialogInput are the standard fonts that you can use on every system. But you can also use other fonts available on your system. See the section on Font and FontMetrics.

#
20.	You can place a button inside a button, since a button is an instance of Container.
a. true
b. false
Key:a All the public methods in Container are inherited by JButton. You can add components into a button and set the layout in a button. Practically, you never need to add components into a button. One thing I would like to see in the future version of Java is to disable public methods of its superclass in the subclasses.

#
21.	Suppose you add the same button ten times into the container, the button will appear ten times in the container. 
a. true
b. false
Key:b The button will be displayed only once. Adding the same button into the container any number of times is equivalent to adding it one time.
