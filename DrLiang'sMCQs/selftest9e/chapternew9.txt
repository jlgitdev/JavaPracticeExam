22. What will be displayed by the following code?

    String s1 = "Welcome to Java";
    String s2 = "Welcome to Java";
    System.out.println("s1 == s2 is " + s1 == s2);
a. true
b. false
c. s1 == s2 is true
d. s1 == s2 is false
Key:b This question is very tricky. Since the + operator has higher precedence than the == operator, "s1 == s2 is " + s1 is evaluated first. Therefore, the result is false.
